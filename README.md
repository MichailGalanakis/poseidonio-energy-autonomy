# Ενεργειακή Αυτονομία & Κλιματική Ανθεκτικότητα — Ποσειδώνιο Αθλητικό Κέντρο

Υπολογιστικό μοντέλο και υλικό υποστήριξης της διπλωματικής εργασίας:

> «Ενεργειακή Αυτονομία και Κλιματική Ανθεκτικότητα Μεγάλων Αθλητικών Υποδομών:
> Μελέτη Συστήματος Φωτοβολταϊκών και Αντλιών Θερμότητας για το Ποσειδώνιο
> Αθλητικό Κέντρο Θεσσαλονίκης με χρονικό ορίζοντα το 2040»
> — Νικολέτα Γαλανάκη, Τμήμα Μηχανικών Οικονομίας και Διοίκησης, Παν. Αιγαίου

**Πεδίο μελέτης:** αποκλειστικά το **κολυμβητήριο** του Ποσειδωνίου — οι
τέσσερις δεξαμενές (2 εσωτερικές 50×21 m, εκμάθησης 10×12 m, εξωτερική
50×21 m), το ΖΝΧ των λουτρών και οι χώροι του κλειστού κολυμβητηρίου.
Τα ανοικτά γήπεδα και οι λοιπές εγκαταστάσεις του φορέα (Αλεξάνδρειο,
Ε.Α.Κ. Σταυρούπολης) είναι **εκτός πεδίου** και αναφέρονται μόνο ως πλαίσιο.

## Εκτέλεση

```bash
pip install -r requirements.txt
python3 run_analysis.py                     # με το ενσωματωμένο συνθετικό TMY (ΤΟΤΕΕ)
python3 run_analysis.py --tmy data/tmy.csv  # με πραγματικό TMY από PVGIS (προτεινόμενο)
python3 run_analysis.py --kwp 800           # άλλο μέγεθος Φ/Β στα σενάρια S2–S4
python3 calibrate.py                        # έλεγχος βαθμονόμησης έναντι μετρητή ΕΔΑ
```

**Λήψη πραγματικού TMY:** https://re.jrc.ec.europa.eu/pvg_tools/en/ → καρτέλα
«TMY» → συντεταγμένες 40.579, 22.950 → Download CSV → αποθήκευση ως `data/tmy.csv`.

## Σενάρια

| Σενάριο | Περιγραφή |
|---|---|
| S0 | Υφιστάμενη κατάσταση: λέβητας φυσικού αερίου (βάση σύγκρισης) |
| S1 | Αντλίες θερμότητας, ρεύμα 100 % από το δίκτυο, τρέχον κλίμα |
| S2 | Α/Θ + Φ/Β (Net Billing), τρέχον κλίμα |
| S3 | Α/Θ + Φ/Β, κλίμα 2040 — σενάριο RCP4.5 |
| S4 | Α/Θ + Φ/Β, κλίμα 2040 — σενάριο RCP8.5 |

Επιπλέον, το script σαρώνει μεγέθη Φ/Β 0 → όριο στέγης και εντοπίζει το
βέλτιστο κατά NPV (απαντά στο ερευνητικό ερώτημα 1 της περίληψης).

## Βαθμονόμηση με πραγματικά δεδομένα ✓

Το μοντέλο έχει βαθμονομηθεί έναντι της **πραγματικής κατανάλωσης ΦΑ του
έτους αναφοράς** (ωριαίος PTZ μετρητής ΕΔΑ Θεσσαλονίκης — Η/Μ μελέτη
τριπαραγωγής ΓΓΑ 07/2024, βλ. `docs/05-πραγματικά-δεδομένα.md`):

- Ετήσια: μοντέλο 3.635 MWh vs πραγματικά 3.730 MWh καυσίμου (**−2,5 %**)
- **NMBE −2,5 %** (όριο ±5 %) · **CV(RMSE) 11,7 %** (όριο 15 %) —
  πληρούνται τα κριτήρια ASHRAE Guideline 14 για μηνιαία δεδομένα
- Εκκρεμείς αποκλίσεις: Μάιος +41 % (μεταβατικός μήνας), Δεκ −13 % —
  αναμένεται βελτίωση με το πραγματικό TMY (PVGIS) αντί του συνθετικού

## Ενδεικτικά αποτελέσματα (βαθμονομημένο μοντέλο, συνθετικό TMY)

- Ετήσια θερμική ζήτηση: **≈ 3.27 GWh** τελικά (κυρίαρχες η εξάτμιση/κέλυφος)
- SCOP αντλιών θερμότητας: **≈ 3.3** (βελτιώνεται στο κλίμα 2040: ≈ 3.35)
- Μείωση εκπομπών CO₂ έναντι ΦΑ: **≈ 68 %** σήμερα, **≈ 89 %** το 2040
  (καθώς απανθρακώνεται και το μίγμα του δικτύου)
- Με 500 kWp: αυτονομία ≈ 33 % · NPV ≈ +1,3 M€ · Payback ≈ 7,2 έτη·
  βέλτιστο κατά NPV στο όριο στέγης (800 kWp)

⚠️ Παραδοχές που εκκρεμούν σημειώνονται `[ΑΥΤΟΨΙΑ]`/`[ΒΑΘΜΟΝΟΜΗΣΗ]` στο
`config.py` — βλ. και «Τι εκκρεμεί» στο `docs/05-πραγματικά-δεδομένα.md`.

## Επόμενα βήματα (σειρά προτεραιότητας)

1. ~~Συλλογή πραγματικών δεδομένων κατανάλωσης~~ ✓ (μελέτες ΓΓΑ, PTZ ΕΔΑ) —
   εκκρεμούν: μηνιαία kWh ΔΕΗ Ποσειδωνίου, στοιχεία αυτοψίας (βάθη δεξαμενών,
   RH χώρου, λειτουργία εξωτερικής πισίνας, επιφάνεια στέγης για Φ/Β).
2. ~~Βαθμονόμηση ±10 %~~ ✓ (−2,5 % ετήσια, ASHRAE G14 ΟΚ) — επανάληψη με
   πραγματικό TMY μόλις ληφθεί.
3. Λήψη PVGIS TMY + ακριβών ΔΤ 2040 από Copernicus CDS (αντικατάσταση
   των ενδεικτικών τιμών του `climate.py::MORPHING_2040`).
4. Ανάλυση ευαισθησίας (τιμές ενέργειας, επιτόκιο, COP) — έτοιμη υποδομή
   στο `pv_sizing_sweep`.
5. Σύγκριση με το σενάριο ΣΗΘΥΑ της ΓΓΑ (τριπαραγωγή 360 kWe, στοιχεία στο
   `docs/05-πραγματικά-δεδομένα.md`) — κεφάλαιο συζήτησης της διπλωματικής.
6. Συγγραφή κεφαλαίων με βάση το `docs/01-δομή-διπλωματικής.md`.
