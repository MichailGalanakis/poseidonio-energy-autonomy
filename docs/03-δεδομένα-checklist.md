# Checklist δεδομένων — τι χρειάζεται το μοντέλο από την πραγματικότητα

Κάθε στοιχείο δείχνει και **πού μπαίνει** στον κώδικα (`config.py` εκτός
αν σημειώνεται αλλιώς). Προτεραιότητα: ★★★ κρίσιμο, ★★ σημαντικό, ★ καλό να υπάρχει.

## Α. Λογαριασμοί & καταναλώσεις ★★★
- [ ] Λογαριασμοί φυσικού αερίου 2–3 ετών (μηνιαία kWh ή Nm³) → βαθμονόμηση (§4.7)
- [ ] Λογαριασμοί ηλεκτρικού ρεύματος (μηνιαία kWh, ισχύς) → συνολικό προφίλ
- [ ] Τιμολόγια: €/kWh ΦΑ και ρεύματος που όντως πληρώνει ο φορέας → `Economics`
- [ ] Καταναλώσεις νερού (αναπλήρωση δεξαμενών) → επαλήθευση εξάτμισης/ανανέωσης

## Β. Δεξαμενές ★★★
- [ ] Ακριβείς διαστάσεις & βάθη κάθε δεξαμενής → `Site.pools`
- [ ] Θερμοκρασίες λειτουργίας νερού (ρυθμίσεις BMS/θερμοστατών)
- [ ] Ωράριο λειτουργίας & προγράμματα χρήσης (σωματεία, κοινό, σχολές)
- [ ] Χρήση καλυμμάτων τη νύχτα; (ναι/όχι — μεγάλη επίδραση στην εξάτμιση)
- [ ] Ρυθμός ανανέωσης νερού (υγειονομικός κανονισμός/πρακτική)

## Γ. Χώρος & Η/Μ εγκαταστάσεις ★★
- [ ] Θερμοκρασία & υγρασία αίθουσας (μετρήσεις ή ρυθμίσεις) → `Hall`
- [ ] ΚΚΜ: παροχές, ύπαρξη/απόδοση ανάκτησης θερμότητας → `heat_recovery_eff`
- [ ] Λέβητες: τύπος, ονομαστική ισχύς, έτος, βαθμός απόδοσης → `boiler_eff`
- [ ] Γεωμετρία κτιρίου & μονώσεις (για εκτίμηση UA) → `envelope_ua_w_k`
- [ ] Μέση ημερήσια προσέλευση λουομένων → `DomesticHotWater.users_per_day`

## Δ. Επιφάνειες Φ/Β (αυτοψία) ★★★
- [ ] Εμβαδόν, προσανατολισμός, κλίση κάθε διαθέσιμης στέγης/στεγάστρου
      → `PVSystem.available_area_m2`
- [ ] Σκιάσεις (γειτονικά κτίρια, δέντρα, στηθαία) — φωτογραφίες + σκαρίφημα
- [ ] Στατική επάρκεια στέγης (έστω ποιοτική εκτίμηση, αναφορά ως περιορισμός)
- [ ] Θέση μετασχηματιστή/πίνακα — απόσταση για διασύνδεση

## Ε. Εξωτερικά δεδομένα (δωρεάν, online) ★★★
- [ ] PVGIS TMY CSV για 40.579, 22.950 → `data/tmy.csv`
      (https://re.jrc.ec.europa.eu/pvg_tools/en/)
- [ ] PVGIS-PVcalc ετήσια παραγωγή ίδιων παραμέτρων → επικύρωση §4.4
- [ ] Copernicus CDS: μηνιαία ΔΤ/ΔRH EURO-CORDEX 2031–2050 vs 1991–2020,
      RCP4.5 & RCP8.5, κελί Θεσσαλονίκης → `climate.py::MORPHING_2040`
- [ ] ΔΑΠΕΕΠ: τρέχων συντελεστής εκπομπών ελληνικού μίγματος → `ef_grid_2026`
- [ ] Τιμή αναφοράς έγχυσης Net Billing (ΥΠΕΝ/ΡΑΑΕΥ) → `injection_price_eur_kwh`

## ΣΤ. Οικονομικά στοιχεία αγοράς ★★
- [ ] 2–3 ενδεικτικές προσφορές/τιμοκατάλογοι Φ/Β (€/kWp εγκατεστημένο)
- [ ] Τιμές Α/Θ μεγάλης κλίμακας (€/kW_th) + φύλλα EN 14511 → επικύρωση COP
- [ ] Διαθέσιμα χρηματοδοτικά εργαλεία (πρόγραμμα «Ηλέκτρα», ΕΣΠΑ) → σενάριο
      επιδότησης στην ανάλυση ευαισθησίας

## Πρακτικά για την αυτοψία
Πήγαινε με: μετροταινία/laser, φωτογραφική, θερμόμετρο-υγρασιόμετρο,
έντυπο καταγραφής (φτιάξε από αυτό το checklist), και ζήτα από τον
υπεύθυνο Η/Μ: μονογραμμικό ηλεκτρικό σχέδιο, μηχανολογικά σχέδια
λεβητοστασίου, τυχόν παλαιότερες ενεργειακές μελέτες/ΠΕΑ του κτιρίου.
